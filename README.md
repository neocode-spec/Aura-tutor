 Aura AI Exam Prep Tutor

Iris is a dedicated, active-recall AI tutor built to help students master complex concepts, practice with targeted exam questions, and score high on assessments.

 🚀 Features
- Active Recall Engine: Tests understanding after every key concept.
- Marking Scheme Focus: Structures answers around standard keywords and examination guidelines.
- Custom Rigor Modes: Adjust tutoring depth from beginner explanations to hardcore practice drills.

 🛠️ Tech Stack
- UI Framework:[Streamlit](https://streamlit.io/)
- LLM Provider: [Groq Cloud API](https://console.groq.com/)
- Model: `llama-3.3-70b-versatile`
- Hosting: [Render](https://render.com)
